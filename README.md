 📊 HR Analytics Dashboard

📖 Project Description

The HR Analytics Dashboard is an interactive data analytics project developed using **Microsoft Excel** to analyze employee data and generate meaningful business insights. The primary objective of this project is to help Human Resource (HR) departments understand workforce trends, identify employee attrition patterns, and support strategic decision-making through data visualization.

The dashboard transforms raw HR data into easy-to-understand charts, graphs, and Key Performance Indicators (KPIs). It enables HR professionals to monitor important metrics such as employee attrition, salary distribution, department-wise workforce, gender diversity, and employee experience. Using Excel features like **Pivot Tables, Pivot Charts, Slicers, Conditional Formatting, and KPI Cards**, users can interactively explore the data and make informed business decisions.

This project demonstrates practical applications of Business Analytics and Data Visualization in solving real-world HR challenges using Microsoft Excel.

# 📂 Dataset Information

The project uses an **HR Employee Dataset** containing workforce-related information. The dataset includes multiple employee attributes that help analyze HR performance and workforce behavior.

### Dataset Columns

* Employee ID
* Age
* Gender
* Department
* Job Role
* Education
* Marital Status
* Business Travel
* Monthly Income
* Job Satisfaction
* Performance Rating
* Years at Company
* Years in Current Role
* Total Working Years
* Overtime
* Attrition

The dataset was cleaned and analyzed before creating the dashboard to ensure accurate results.

# 💡 Key Insights

The dashboard provides several valuable business insights, including:

* Employee Attrition Rate across the organization.
* Departments with the highest and lowest employee count.
* Salary distribution among different departments.
* Gender diversity within the organization.
* Experience level of employees.
* Overall workforce performance through KPIs.
* Interactive filtering for deeper analysis.

These insights help HR managers improve employee retention, workforce planning, recruitment strategies, and organizational performance.
